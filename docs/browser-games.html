This started from the comments of a hacker news thread on half life 2 being playable in a web browser. The blog post is here https://www.slqnt.dev/blog/hl2-in-web.

It was very surprising to me that so many of these games have been ported so I wanted to start a list to track them for a later date.

The List _

Games that you can play in the browser

Quake 3: https://thelongestyard.link/q3a-demo/

Unreal Tournament: https://dos.zone/mp/?lobby=ut

GTA vice city https://quenq.com/apps/vice-city/

Counter Strike: dos.zone/mp/?lobby=cs16

Half Life 1: https://x8bitrain.github.io/webXash/

Half Life 2: https://hl2.slqnt.dev/

Doom 3: https://wasm.continuation-labs.com/d3demo/

Diablo: https://devilutionx.app

Tomb Raider https://eikehein.com/stuff/sabatu

Duke Nukem 3D: https://gawen.me/webduke

Red Alert 2: https://chronodivide.com/
